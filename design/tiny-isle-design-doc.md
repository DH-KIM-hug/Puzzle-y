# 작은 섬 개척 (가제: Tiny Isle) — 게임 기획서

> 1인용 육각 타일 배치 퍼즐 + 일꾼 행동 콤보 + 가벼운 개척. 스프라이트 스태킹 디오라마.
> 작성: 2026-11-21 (v2 — 핵심 규칙을 "무리 크기 = 행동 횟수"로 개정) · 엔진: Godot 4.7 (2D) · 플랫폼: PC(Steam) + 모바일 · 개발 중 테스트는 웹 빌드

---

## 1. 한 줄 소개
빈 육각 섬에 밭·숲·목장·물·집이 그려진 **2칸 타일**을 붙인다. 붙인 칸이 맞닿은 **같은 종류 무리의 크기만큼 그 종류의 일꾼 행동을 반복**한다 — 배가 해안을 한 칸씩 항해하고, 길이 한 칸씩 뻗고, 양떼가 초원을 걷고, 주민이 공사장으로 간다. 행동하는 **길목의 보너스 칸**이 다른 행동을 깨워 **콤보**가 이어지고, 그 모든 움직임이 탁자 위 장난감 같은 섬 위에서 그대로 보인다.

- 메커니즘 계열: 보드게임 Ingenious(육각 + 2칸 타일, 같은 종류 연결) + Witchstone(무리 크기 = 행동 횟수, 행동 길목의 보너스로 콤보). **이름·아트·맵·트랙 구성은 전부 오리지널.**
- 시각 참고: Dorfromantik, Islanders, Townscaper, NIUM(스프라이트 스택)

**왜 이 구조인가**: "무리가 크면 숫자가 커진다"는 계산만 남는다. 재미는 **N번의 작은 선택을 연달아 하며 판을 바꾸는 반복 행동**과, 그 길에서 터지는 보너스 연쇄에 있다.

## 2. 기둥 (Pillars)
1. **한 장의 연쇄** — 타일 한 장이 여러 일꾼 행동을 연달아 깨운다. *판단: 새 규칙이 행동·연쇄를 늘리는가, 장부만 늘리는가 → 행동·연쇄.*
2. **섬마다 다른 숙제** — 기본 평가는 **합산 점수**. 캠페인 섬마다 조건(숙제)이 달라 같은 규칙이 다른 퍼즐이 된다. 균형 평가는 숙제 중 하나. *판단: 숙제가 전략을 바꾸지 않으면 숙제를 바꾼다.*
3. **살아 있는 섬** — 행동이 곧 섬 위의 움직임이다(배·길·양떼·주민·건물). *판단: UI 숫자보다 섬 위 움직임 먼저.*
4. **보이는 선택** — 무작위로 결과가 바뀌지 않는다. 놓기 전에 얻을 행동 횟수가 보이고, 행동 한 걸음마다 갈 수 있는 곳과 밟으면 생기는 보너스가 미리 보인다. *판단: 숨은 결과·무작위보다 보이는 결과.*

**안티 기둥**: 실시간·시간 압박 없음 / 복잡한 경제(자원 종류 최소, 가격 변동 없음) 없음 / 전투·재해 파괴 없음 / 처리 중 무작위(주사위) 없음(무작위는 손패 뽑기만) / 결제 = 점수 없음.

## 3. 핵심 규칙

### 3.1 섬과 타일
- 뾰족한 위쪽(pointy-top) 육각 격자. 섬마다 모양·바다·산(배치 불가) 칸이 다르다.
- 섬에는 미리 찍힌 **지형 표시**가 있다: 해안의 **항구**·**보물 섬**, 땅 위의 **명소 터**(풍차 터·등대 터·시장 터·우물 터), **마을 광장**(길 시작점), **양 우리**.
- 타일 = 인접한 육각 2칸, 각 칸에 종류 1개(같아도 됨). 종류: **물 · 숲 · 밭 · 목장 · 집**.
- 손패 3장, 놓으면 1장 보충(가방에서 시드 기반 뽑기). 회전 6방향.
- 학습 순서: 첫 섬은 물·숲·집(배 항해·길 놓기·주민 파견) 3종 → 이후 섬에서 밭·목장 추가.

### 3.2 무리 → 행동 횟수
- 타일을 놓으면 **두 칸 각각**: 그 칸을 포함해 연결된 같은 종류 무리 크기 **N** → 그 종류 **행동 N회**를 얻는다.
- 두 칸의 행동은 **플레이어가 순서를 골라** 실행한다. 보너스로 얻은 행동은 행동 대기열에 쌓이고, 원하는 순서로 쓴다.
- 행동을 다 쓰거나 남은 행동을 "버리기"로 넘기면 턴 종료 → 1장 보충.

### 3.3 일꾼 행동 5종 (1회 = 한 걸음)
| 타일 | 행동 | 한 걸음 | 길목 보너스 (연쇄) | 결과·점수 |
|---|---|---|---|---|
| 물 | **배 항해** | 배 말을 섬을 두른 해안 고리에서 1칸 이동(양방향) | **보물 섬** 칸에 들어가면 그 칸에 적힌 보너스 행동 획득(예: 길 +2). 한 섬마다 1회 | **항구**에 들어가면 곳간의 곡식 1을 배달 → 3점 |
| 숲 | **길 놓기** | 기존 길(시작: 마을 광장)에 이어서 인접한 땅 1칸에 길 깔기 | 길이 **명소 터**에 닿으면 그 명소의 **공사장이 열리고** 주민 파견 +1 | 연결된 명소마다 점수, 길 끝이 해안에 닿으면 새 항구 생성 |
| 밭 | **수확** | 곳간 트랙에서 곡식 말 1칸 전진 | 트랙의 **보너스 칸**(예: 3 → 배 +1, 6 → 양떼 +2, 10 → 주민 +1, 15 → 5점) | 곡식은 겨울 식량·항구 배달에 쓰임 |
| 목장 | **양떼 몰기** | 양떼 말을 인접한 땅 1칸으로 이동 | **밭**을 지나가면 거름(그 밭 무리의 다음 수확 +1). 빈 초원 칸을 처음 밟으면 양모 1 | **양 우리**로 돌아오면 모은 양모 1당 2점, 양모는 0으로 |
| 집 | **주민 파견** | 열린 공사장 하나에 주민 말 1명 배치 | 공사장이 다 차면 **건물 완성 → 규칙이 바뀜** | 건물 완성 점수 |

**건물 효과 (완성 시 영구)**
- **풍차**(주민 4): 이후 수확 행동마다 +1칸.
- **등대**(주민 5): 이후 배 항해 행동마다 +1칸, 항구 배달 점수 2배.
- **시장**(주민 3): 이후 양 우리뿐 아니라 시장에서도 양모 정산.
- **우물**(주민 2): 겨울에 필요한 곡식 −2.

**연쇄 예시** (물+숲 타일, 물 무리 3·숲 무리 4)
1. 배 항해 3회: 2칸째 보물 섬 → "길 +2" 획득.
2. 길 놓기 4+2 = 6회: 길이 풍차 터에 닿음 → 풍차 공사장 열림, 주민 파견 +1.
3. 주민 파견 1회 → 풍차가 완성되면 이후 모든 수확이 +1.

### 3.4 계절과 식량
- 한 섬 = 4계절 × 6장 = 24장(섬마다 조정 가능).
- 계절 끝: 집 무리 크기 합계 2당 곡식 1 소비(올림). 부족분 1당 −2점. 우물이 있으면 −2 경감.

### 3.5 점수와 별
- 점수 = 항구 배달 + 명소 연결 + 양모 정산 + 건물 완성 + 곳간 트랙 보너스 − 식량 페널티.
- 섬 숙제 예: 등대 완성 필수 / 배달 5회 이상 / 균형 섬(점수 = 가장 낮은 항목 × N) / 숲 타일 금지 / 배가 섬을 한 바퀴.
- 섬마다 별 1~3 기준.

### 3.6 모드
- **캠페인**: 손으로 설계한 섬 10~20개(MVP 10). 섬마다 지형 표시 배치와 숙제가 다름.
- **무작위 섬 도전**: 캠페인 클리어 후 해금. 무작위 섬 + 무작위 지형 표시 + 숙제 조합, 최고 점수.

### 3.7 결정성
- 규칙 처리(무리 크기, 행동 이동 가능 칸, 보너스 발동, 점수)는 노드와 무관한 **결정적 순수 모듈**. 미리보기와 실제 처리가 같은 함수를 쓴다. 무작위는 손패 뽑기에만, 시드 주입.

## 4. 조작·UX (확정)
- **놓기 흐름**: 손패 카드를 탭 → 고스트 조각이 섬 위에 붙어 포인터/손가락을 따라감 → **고스트를 탭하면 회전**, 가능한 방향은 후보 점으로 표시 → 고스트 옆 도구막대(↻ 회전 · ✕ 취소 · ✓ 확정).
  - 터치: ✓로 확정. 마우스: 좌클릭 즉시 놓기(설정에서 "항상 확인" 가능).
  - **스마트 방향**: 놓을 수 없는 방향이면 자동으로 가능한 방향으로 회전(기본 켬).
- **놓기 전 미리보기**: 두 칸의 무리 하이라이트 + 얻을 행동 아이콘과 횟수(예: ⛵×3, 🌲×4)를 섬 위와 행동 바에 표시.
- **행동 실행**: 화면 하단 **행동 바**에 행동 말들이 쌓임 → 말을 탭하면 그 행동 모드 진입 → 섬 위에 **한 걸음에 갈 수 있는 칸**이 빛나고, 보너스 칸은 아이콘으로 표시, **남은 횟수로 닿을 수 있는 보너스 칸**은 은은하게 강조 → 칸을 탭해 한 걸음씩 진행(마우스는 드래그로 여러 칸 경로 그리기 가능). "되돌리기"는 현재 행동 안에서만 허용, "남은 행동 버리기" 버튼.
  - 반복 행동이 지루해지지 않게: 연속 걸음은 빠르게 이어 그리기, 단순 반복(수확 트랙 전진)은 한 번에 N칸 진행 버튼.
- **카메라**: 섬이 화면 ~90%를 채우게 자동 맞춤, 줌 0.85~2.5배(휠/핀치), 드래그 이동, **60° 스냅 회전**, 행동 중인 말로 포커스.
- **HUD**: 좌우 텍스트 패널 없음. 상단에 점수·계절·곳간·양모·숙제 진행 칩. 하단에 손패 + 행동 바. 상세 규칙은 필요할 때만 여는 서랍.
- **규칙 학습**: 4단계 튜토리얼 섬(① 무리 = 행동 횟수 ② 배 항해와 보물 섬 ③ 길과 명소 → 공사장 ④ 주민 파견과 건물 효과) + 상황별 코치 말풍선.
- 터치 대상 최소 ~64px(1080p 기준). 가로 16:9(1280×720 기준), 모바일 가로 지원.
- **합격 기준(예)**: 처음 하는 사람이 설명 없이 10초 안에 조각을 회전해 놓는다 / 첫 섬에서 보물 섬 보너스로 다른 행동을 얻는 연쇄를 스스로 1회 이상 만든다 / 한 턴(행동 포함) 평균 30초 이내 / 미리보기와 실제 결과 100% 일치.

## 5. 비주얼 — 정통 픽셀 스프라이트 스태킹
**비주얼 규칙: "섬은 탁자 위의 장난감 보드게임이다."** 처음 화면부터 예뻐야 한다(플레이스홀더 금지).

- **기법**: 모든 오브젝트는 작은 **복셀 모델**(데이터 또는 규칙 생성) → 로드 시 **층별 픽셀 단면 이미지**로 굽기 → 최근접(nearest) 정수 확대 → 층마다 1픽셀씩 올려 카메라 각도에 맞춰 회전해 그리기(NIUM 방식). 사용자 PC의 `sprite-stacking` 스킬 활용.
- **해상도**: 저해상도 버퍼(예: 640×360)를 정수 배율로 확대해 픽셀이 선명하게. 회전은 64스텝 스냅 권장(캐시).
- **음영**: 한 방향 빛(윗면 밝게/옆면 어둡게/모서리 AO)을 복셀 색에 미리 굽기. 제한된 픽셀 팔레트.
- **지면**: 섬 전체를 하나의 지면 스택으로 — 빈 칸은 베이지 판이 아니라 **풀·꽃이 있는 초원**, 칸 경계가 자연스럽게 이어짐.
- **숲 (디테일 최우선)**: 수종 4종(활엽·침엽·자작·과일) 복셀 생성기, 칸당 5~9그루(무리 크기에 비례), 바닥에 덤불·고사리·버섯·바위·쓰러진 통나무·이끼, 숲 가장자리는 밝고 안쪽은 짙게, 이웃 숲 칸 사이 다리 나무로 수관이 이어짐. 성장: 묘목 → 작은 숲 → 오래된 숲.
- **밭**: 이랑·작물 줄, 곳간·허수아비·건초 더미. **목장**: 울타리·양, 양 우리. **물**: 연잎·갈대·선착장. **집**: 오두막 → 정원 딸린 집 → 광장·우물.
- **행동 말(장난감 말)**: 배(돛단배), 길(돌길 타일이 한 칸씩 깔림), 양떼(양 무리가 걸어감), 주민(작은 말 모양 사람), 곳간 트랙 말. 명소 터는 말뚝과 깃발, 공사장은 비계 → 완성 건물(풍차가 돌아감, 등대 불빛).
- **바다·해안**: 디더링으로 깊이 표현, 모래 해변, 프레임 거품, 해안 바위, 해안 고리 위 항구·보물 섬 표시. 섬 둘레 나무 보드 테두리.
- **디오라마 연출**: 따뜻한 원목 탁자 배경, 틸트시프트 블러(위아래), 은은한 비네트.
- **타일 구분**: 색 + 실루엣 + 오브젝트 3중(색약 대응, 흑백에서도 구분).

### 5.1 살아 있는 섬 (상시 애니메이션 + 행동 연출)
- 상시: 밀이 물결치고 나무가 흔들림(층 높이에 비례한 가로 오프셋) / 물 반짝임·물고기 점프 / 해안 파도 / 굴뚝 연기·창문 불빛 / 구름 그림자·새 / 계절 색감(봄 연두·여름 밝게·가을 따뜻·겨울 차갑게 + 눈). 모션 줄이기 설정 존중.
- 행동: 배가 물살을 가르며 한 칸씩 이동, 길 돌이 톡톡 깔림, 양떼가 줄지어 걷고 지나간 밭에 거름 반짝임, 주민이 길 따라 공사장으로 걸어감, 건물이 비계에서 완성되며 튀어오름. 보너스 칸을 밟으면 아이콘이 터지며 행동 바에 새 말이 날아와 쌓임(연쇄가 눈에 보임).

## 6. 사운드
- 음악과 효과음은 **ElevenLabs**로 제작(효과음: sound-generation API, 음악: music API). 키는 저장소에 넣지 않고 로컬 `~/.config/elevenlabs/key`에서 읽는 생성 스크립트로(참고: paper-tale-theater/tools/elevenlabs).
- 효과음: 나무 타일 딸깍·놓기, 행동별 한 걸음 소리(노 젓기·돌 깔기·양 울음·발소리·곡식 쏟기), 보너스 획득, 건물 완성, 계절 전환, 식량 정산, 섬 완성 팡파르, UI.
- 음악: 계절별 잔잔한 어쿠스틱 루프, 섬 완성 짧은 징글.
- ElevenLabs 음원의 상업적 사용은 유료 플랜 라이선스 확인.

## 7. 기술
- Godot 4.7, GDScript, 2D, Compatibility 렌더러(웹·모바일·PC), 텍스처 필터 nearest.
- 규칙 코어(배치·무리·행동 이동 규칙·보너스·건물 효과·점수)는 결정적 순수 모듈, gdUnit4 단위 테스트("미리보기 = 실제 결과", 행동별 이동 가능 칸, 보너스 발동).
- 성능 목표: 섬 가득(~100칸 × 오브젝트 × 층) 60fps — 회전 스텝 캐시, 실기기 측정 필수.

## 8. 수익 모델
무료 + 광고(보상형 위주) + 소액결제(꾸미기·편의·섬 팩). **결제로 점수·별을 살 수 없음.** 확률형 상품 계획 없음(넣는다면 확률 공개 의무).

## 9. 범위
**MVP 가설**: 플레이어는 무리를 키워 얻은 행동 횟수로 섬 위에서 한 걸음씩 선택하는 반복 행동을 즐기고, 길목 보너스가 다른 행동을 깨우는 연쇄를 스스로 설계하며, 같은 섬을 별 3개까지 다시 한다.

**MVP 필수**
1. 육각 섬 + 2칸 타일 배치(손패 3, 회전, 지형 제약, 위 UX)
2. 무리 = 행동 횟수 + 일꾼 행동 5종(배 항해·길 놓기·수확·양떼 몰기·주민 파견) + 길목 보너스 연쇄 + 건물 4종
3. 놓기 전 미리보기 + 행동 한 걸음 미리보기(결정적 해석기)
4. 계절 진행 + 식량 정산
5. 캠페인 섬 10개(섬별 지형 표시·숙제·별) + 튜토리얼 섬
6. 스프라이트 스택 디오라마 + 행동 연출 + 상시 애니메이션 + 로컬 세이브

**MVP 제외**: 무작위 섬 모드, 광고·결제, 스토어 빌드, 추가 건물, 점수판, 꾸미기.

| 단계 | 내용 | 기간 |
|---|---|---|
| T0 프로토타입 | 섬 1개, 행동 3종(배·길·주민) + 건물 2종, 보물 섬·명소, 스프라이트 스택 섬 | 2~4주 |
| T1 MVP | 섬 10개, 행동 5종, 건물 4종, 위 MVP 6항목 | 3~4개월 |
| T2 소프트런치 | 섬 20개, 무작위 섬 모드, 광고·결제, PC·모바일 빌드 | 6개월+ |
| T3 풀 비전 | 섬 30+, 건물·행동 추가, 점수판, 꾸미기, 이벤트 섬 | 출시 후 |

## 10. 열린 질문
- **결정 피로**: 큰 무리(N=8 이상)일 때 한 턴이 너무 길어지지 않는가 → 경로 그리기·자동 진행 버튼·무리 크기 상한(예: 행동 최대 6회) 검토.
- 행동 5종의 균형: 특정 행동(예: 길 놓기)만 강하지 않은가 → 섬 숙제와 보너스 배치로 조정.
- 보물 섬·명소·곳간 보너스 칸의 개수와 배치(섬 설계 도구 필요).
- 양떼 몰기의 재미(이동 규칙이 너무 자유로우면 고민이 없고, 너무 묶이면 답답함).
- 성장 단계 기준값(무리 크기 몇에서 묘목→숲→오래된 숲?).
- 아직 놓지 않은 칸의 표현(초원 vs 미개척 안개).
- 계절 식량 정산이 재미인가 부담인가.
- 터치로 한 걸음씩 탭하는 조작이 편한가(경로 그리기와 비교).
