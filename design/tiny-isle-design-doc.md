# 작은 섬 개척 (가제: Tiny Isle) — 게임 기획서

> 1인용 육각 타일 배치 퍼즐 + 가벼운 개척 경영. 스프라이트 스태킹 디오라마.
> 작성: 2026-11-21 · 엔진: Godot 4.7 (2D) · 플랫폼: PC(Steam) + 모바일 · 개발 중 테스트는 웹 빌드

---

## 1. 한 줄 소개
빈 육각 섬에 밭·숲·목장·물·집이 그려진 **2칸 타일**을 한 장씩 붙인다. 붙인 칸이 맞닿은 **같은 종류 무리**가 클수록 큰 일이 일어나고, 그 일이 **자원 트랙의 문턱**을 넘겨 다음 보너스를 깨우는 **연쇄**로 — 탁자 위 장난감 보드게임 같은 섬이 자라난다.

- 메커니즘 계열: 보드게임 Ingenious(육각 + 2칸 타일, 같은 종류 연결) + Witchstone(무리 크기만큼 행동 → 콤보). **이름·아트·트랙 구성은 전부 오리지널.**
- 시각 참고: Dorfromantik, Islanders, Townscaper, NIUM(스프라이트 스택)

## 2. 기둥 (Pillars)
1. **한 장의 연쇄** — 타일 한 장이 여러 행동을 연달아 깨운다. *판단: 새 규칙이 연쇄를 늘리는가, 장부만 늘리는가 → 연쇄.*
2. **섬마다 다른 숙제** — 기본 평가는 **합산 점수**. 캠페인 섬마다 조건(숙제)이 달라 같은 규칙이 다른 퍼즐이 된다. 균형 평가(가장 약한 지표로 채점)는 숙제 중 하나. *판단: 숙제가 전략을 바꾸지 않으면 숙제를 바꾼다.*
3. **살아 있는 섬** — 모든 숫자는 섬 위에서 보인다. *판단: UI 숫자보다 섬 모습 먼저.*
4. **보이는 결과** — 놓기 전에 발동·연쇄를 미리 본다. *판단: 무작위보다 예측 가능. 미리보기 ≠ 실제 결과면 버그.*

**안티 기둥**: 실시간·시간 압박 없음 / 복잡한 경제(자원 6종 이하, 가격 변동 없음) 없음 / 전투·재해 파괴 없음 / 처리 중 무작위(주사위) 없음(무작위는 손패 뽑기만) / 결제 = 점수 없음.

## 3. 핵심 규칙

### 3.1 섬과 타일
- 뾰족한 위쪽(pointy-top) 육각 격자. 섬마다 모양·바다·산(배치 불가) 칸이 다르다.
- 타일 = 인접한 육각 2칸, 각 칸에 종류 1개(같아도 됨).
- 타일 종류: **밭(곡식) · 숲(목재) · 목장(양모) · 물(물고기) · 집(주민)**. 이후 해금 1종(예: 시장).
- **첫 섬은 자원 3종(밭·숲·집)으로 시작**하고 섬을 진행하며 종류를 늘린다(학습 단순화).
- 손패 3장, 놓으면 1장 보충(가방에서 시드 기반 뽑기). 회전 6방향.

### 3.2 무리 발동
- 놓은 **두 칸 각각**: 그 칸을 포함해 연결된 같은 종류 무리 크기 N → 그 종류 자원 +N.
  - 밭 → 곡식, 숲 → 목재, 목장 → 양모, 물 → 물고기, 집 → 주민

### 3.3 자원 트랙과 연쇄
- 각 자원은 트랙. **5의 배수를 넘을 때마다** 그 트랙의 보너스가 터진다. 보너스는 **모두 +2**로 통일.
- 보너스는 고리로 이어진다: **곡식 → 주민 → 목재 → 양모 → 물고기 → 곡식**
  - 곡식 문턱 → 주민 +2 (풍년) / 주민 → 목재 +2 (일손) / 목재 → 양모 +2 (울타리) / 양모 → 물고기 +2 (교역) / 물고기 → 곡식 +2 (거름)
- 보너스는 큐 순서(너비 우선)로 처리, 연쇄 깊이 상한 8.
- 문턱까지 남은 양은 자원 칩의 **링(5칸)**으로 표시.
- 해석은 **결정적 순수 함수**: 미리보기와 실제 배치가 같은 함수를 쓴다.

### 3.4 계절과 식량
- 한 섬 = 4계절 × 6장 = 24장(섬마다 조정 가능).
- 계절 끝: 주민 2명당 곡식 1 소비(올림). 부족분 1당 −2점. 인구에 따라 새 타일 해금.

### 3.5 점수와 별
- 기본 점수 = 모든 자원 트랙 합계 − 식량 페널티.
- 섬 숙제 예: 균형 섬(점수 = 가장 낮은 자원 × 5), 숲 타일 금지, 물 2배, 장수 제한, 특정 연쇄 깊이 달성.
- 섬마다 별 1~3 기준.

### 3.6 모드
- **캠페인**: 손으로 설계한 섬 10~20개(MVP 10).
- **무작위 섬 도전**: 캠페인 클리어 후 해금. 무작위 섬 + 무작위 숙제 조합, 최고 점수.

## 4. 조작·UX (확정)
- **놓기 흐름**: 손패 카드를 탭 → 고스트 조각이 섬 위에 붙어 포인터/손가락을 따라감 → **고스트를 탭하면 회전**, 가능한 방향은 후보 점으로 표시 → 고스트 옆 도구막대(↻ 회전 · ⇄ 뒤집기 · ✕ 취소 · ✓ 확정).
  - 터치: ✓로 확정. 마우스: 좌클릭 즉시 놓기(설정에서 "항상 확인" 가능).
  - **스마트 방향**: 놓을 수 없는 방향이면 자동으로 가능한 방향으로 회전(기본 켬).
  - 회전 입력은 2종으로 축소(고스트 탭/↻, 마우스 휠).
- **카메라**: 섬이 화면 ~90%를 채우게 자동 맞춤, 줌 0.85~2.5배(휠/핀치), 드래그 이동, **60° 스냅 회전** 유지, 배치 지점으로 포커스.
- **HUD**: 좌우 패널 제거. 상단에 자원 칩(아이콘 + 값 + 문턱 링)을 **연쇄 고리 순서**대로 배치. 미리보기는 **섬 위**(무리 하이라이트, "+N" 라벨)와 **칩 위**(증가량, 문턱 터짐 표시)에 표시. 텍스트 상세는 필요할 때만 여는 서랍.
- **규칙 학습**: 4단계 튜토리얼 섬 + 상황별 코치 말풍선 + 연쇄 스토리텔링 연출(무리 → 칩 → 다음 칩으로 흐르는 화살표, 최대 2.5초, 탭하면 스킵).
- 터치 대상 최소 ~64px(1080p 기준). 가로 16:9(1280×720 기준), 모바일 가로 지원.
- **합격 기준(예)**: 처음 하는 사람이 설명 없이 10초 안에 조각을 회전해 놓는다 / 첫 판 안에 "무리가 클수록 많이 얻는다"를 말로 설명할 수 있다 / 미리보기와 실제 결과 100% 일치.

## 5. 비주얼 — 정통 픽셀 스프라이트 스태킹
**비주얼 규칙: "섬은 탁자 위의 장난감 보드게임이다."** 처음 화면부터 예뻐야 한다(플레이스홀더 금지).

- **기법**: 모든 오브젝트는 작은 **복셀 모델**(데이터 또는 규칙 생성) → 로드 시 **층별 픽셀 단면 이미지**로 굽기 → 최근접(nearest) 정수 확대 → 층마다 1픽셀씩 올려 카메라 각도에 맞춰 회전해 그리기(NIUM 방식). 사용자 PC의 `sprite-stacking` 스킬 활용.
- **해상도**: 저해상도 버퍼(예: 640×360)를 정수 배율로 확대해 픽셀이 선명하게. 회전은 64스텝 스냅 권장(캐시).
- **음영**: 한 방향 빛(윗면 밝게/옆면 어둡게/모서리 AO)을 복셀 색에 미리 굽기. 제한된 픽셀 팔레트.
- **지면**: 섬 전체를 하나의 지면 스택으로 — 빈 칸은 베이지 판이 아니라 **풀·꽃이 있는 초원**, 칸 경계가 자연스럽게 이어짐.
- **숲 (디테일 최우선)**: 수종 4종(활엽·침엽·자작·과일) 복셀 생성기, 칸당 5~9그루(무리 크기에 비례), 바닥에 덤불·고사리·버섯·바위·쓰러진 통나무·이끼, 숲 가장자리는 밝고 안쪽은 짙게, 이웃 숲 칸 사이 다리 나무로 수관이 이어짐. 성장: 묘목 → 작은 숲 → 오래된 숲.
- **밭**: 이랑·작물 줄, 단계에 따라 허수아비·건초 더미. **목장**: 울타리·양, 크면 헛간. **물**: 연잎·갈대, 크면 선착장. **집**: 오두막 → 정원 딸린 집 → 광장·우물.
- **바다·해안**: 디더링으로 깊이 표현, 모래 해변, 프레임 거품, 해안 바위. 섬 둘레 나무 보드 테두리.
- **디오라마 연출**: 따뜻한 원목 탁자 배경, 틸트시프트 블러(위아래), 은은한 비네트.
- **타일 구분**: 색 + 실루엣 + 오브젝트 3중(색약 대응, 흑백에서도 구분).

### 5.1 살아 있는 섬 (상시 애니메이션)
밀이 물결치고 나무가 흔들림(층 높이에 비례한 가로 오프셋) / 양이 목장 칸 안에서 돌아다니고 풀 뜯기 / 물 반짝임·물고기 점프 / 해안 파도·작은 배 / 굴뚝 연기·창문 불빛·이웃 집 사이를 걷는 주민(주민 수에 비례) / 구름 그림자·새 / 계절 색감(봄 연두·여름 밝게·가을 따뜻·겨울 차갑게 + 눈) / 놓으면 오브젝트가 통통 튀며 솟고, 무리가 커지면 한 단계 자라며 바운스. 모션 줄이기 설정 존중.

## 6. 사운드
- 음악과 효과음은 **ElevenLabs**로 제작(효과음: sound-generation API, 음악: music API). 키는 저장소에 넣지 않고 로컬 `~/.config/elevenlabs/key`에서 읽는 생성 스크립트로(참고: paper-tale-theater/tools/elevenlabs).
- 효과음: 나무 타일 딸깍·놓기, 무리 발동, 문턱 터짐(연쇄 단계마다 음 상승), 계절 전환, 식량 정산, 섬 완성 팡파르, UI.
- 음악: 계절별 잔잔한 어쿠스틱 루프, 섬 완성 짧은 징글.
- ElevenLabs 음원의 상업적 사용은 유료 플랜 라이선스 확인.

## 7. 기술
- Godot 4.7, GDScript, 2D, Compatibility 렌더러(웹·모바일·PC), 텍스처 필터 nearest.
- 규칙 코어(배치·무리·트랙 연쇄·점수)는 노드와 무관한 **결정적 순수 모듈**, 미리보기와 실제 처리 공유, 무작위는 시드 주입. gdUnit4 단위 테스트("미리보기 = 실제 결과").
- 성능 목표: 섬 가득(~100칸 × 오브젝트 × 층) 60fps — 회전 스텝 캐시, 실기기 측정 필수.

## 8. 수익 모델
무료 + 광고(보상형 위주) + 소액결제(꾸미기·편의·섬 팩). **결제로 점수·별을 살 수 없음.** 확률형 상품 계획 없음(넣는다면 확률 공개 의무).

## 9. 범위
**MVP 가설**: 플레이어는 미리보기를 보며 무리 발동과 트랙 연쇄를 설계하고, 연쇄가 섬 위에 자라는 순간에 재미를 느껴 같은 섬을 별 3개까지 다시 한다.

**MVP 필수**
1. 육각 섬 + 2칸 타일 배치(손패 3, 회전, 지형 제약, 위 UX)
2. 무리 발동 + 트랙 연쇄 + 섬 위 미리보기(결정적 해석기)
3. 타일 6종(밭·숲·목장·물·집 + 해금 1)
4. 계절 진행 + 식량 정산
5. 캠페인 섬 10개(섬별 숙제·별) + 튜토리얼 섬
6. 스프라이트 스택 디오라마 + 상시 애니메이션 + 로컬 세이브

**MVP 제외**: 무작위 섬 모드, 광고·결제, 스토어 빌드, 건물 다수, 점수판, 꾸미기.

| 단계 | 내용 | 기간 |
|---|---|---|
| T0 프로토타입 | 섬 1개, 타일 3~4종, 배치·연쇄·미리보기, 스프라이트 스택 섬 | 2~4주 |
| T1 MVP | 섬 10개, 타일 6종, 위 MVP 6항목 | 3~4개월 |
| T2 소프트런치 | 섬 20개, 무작위 섬 모드, 광고·결제, PC·모바일 빌드 | 6개월+ |
| T3 풀 비전 | 섬 30+, 건물 다수, 점수판, 꾸미기, 이벤트 섬 | 출시 후 |

## 10. 열린 질문
- 성장 단계 기준값(무리 크기 몇에서 묘목→숲→오래된 숲?)
- 아직 놓지 않은 칸의 표현(초원 vs 미개척 안개)
- 연쇄가 너무 자주 터져 "장부 정리"처럼 느껴지지 않는가(이전 프로토타입: 무작위 배치 25%, 잘 고른 배치 59%가 2단 이상) — 문턱 간격·보너스 크기로 조정
- 계절 식량 정산이 재미인가 부담인가
- 터치 회전 조작이 10초 합격 기준을 통과하는가
