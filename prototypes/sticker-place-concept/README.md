# 말랑 크루 스티커 — 컨셉 프로토타입 (PIVOT #1, 변주 B)

## 가설
크루 모양 조각을 붙여 줄을 지울 때 얼굴 칸이 능력을 쓰고, 그 능력이 다른 얼굴을 지워 연쇄가 터지면,
플레이어는 "얼굴을 어디 둘지" 고민하며 다른 블록 퍼즐과 다르다고 느낀다.
- 신호: 얼굴을 의도적으로 줄·능력 범위에 맞춰 배치 + "다른 게임 같다" 반응 없음 + 자발적 재도전

## 실행 방법
`prototype.html`을 브라우저로 열기. 아래 트레이의 조각을 끌어서 판에 붙인다.
놓을 위치는 반투명 미리보기, 지워질 줄은 색으로, 지워질 얼굴은 점선으로 표시된다.

## 규칙
- 8×8 판, 조각 3개씩, 다 쓰면 새로 3개. 놓을 곳이 없으면 끝
- 가로/세로 줄이 차면 지워짐. 조각마다 크루 얼굴 1칸
- 얼굴이 지워지면 능력: 냥이 십자 할퀴기 / 곰곰 3×3 쿵 / 삐약 알 3개로 거의 찬 줄 채우기
- 능력이 다른 얼굴을 지우면 그 얼굴도 발동 → 도미노 연쇄 (깊이 상한 6)
