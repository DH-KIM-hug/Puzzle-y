## 0. 문제 진단 (플레이테스트 → 원인)

| # | 플레이어 피드백 | 현 프로토타입에서 관찰된 원인 | 위반 원칙 |
|---|---|---|---|
| P1 | 놓기·돌리기가 어색함 | 회전 입력이 5종(R/휠/우클릭/↻/Q·E와 혼동), ↻ 버튼이 손패 옆에 있어 **조각과 떨어져 있음**. 터치는 "같은 칸 두 번 탭"이 숨은 규칙. 고스트가 손가락에 가려짐 | 근접성(조작부는 대상 옆), 발견 가능성, 피츠의 법칙 |
| P2 | 섬이 작고 답답함 | 16:9에서 섬이 화면 폭의 ~45%만 사용(좌·우 패널이 ~40% 점유). 줌/팬 없음. 폰 가로에서 칸 하나 ≈ 40px | 콘텐츠 우선, 터치 타깃 최소 44pt |
| P3 | 규칙을 모름 | 연쇄가 오른쪽 **텍스트 목록**으로만 설명됨. "5마다 → 주민+2"가 칩마다 글로 반복. 연쇄 배너가 섬을 가림(03b). 같은 무리 두 반쪽이 "+2 목재" 두 장으로 겹쳐 보임(08/09) | Pillar 3 "섬 먼저, UI는 보조", Pillar 4 보이는 결과, 점진적 공개 |
| P4 | 패널이 글투성이 | 기본 화면에 상시 노출 문장 15개 이상 | 인지 부하, 점진적 공개 |

## 1. 배치 흐름 (Placement Flow)

### 1.1 상태 기계

```
IDLE ──(손패 카드 탭/클릭 또는 드래그 시작)──▶ CARRYING
CARRYING ──(포인터 이동)──▶ 고스트가 가장 가까운 칸에 스냅 (미리보기 갱신)
CARRYING ──(터치: 손가락 뗌 / 마우스: 칸 위에서 정지)──▶ PARKED (고스트 고정 + 고스트 툴바 표시)
PARKED ──(회전)──▶ PARKED (미리보기 갱신)
PARKED ──(고스트 드래그 / 다른 칸 탭)──▶ PARKED (위치만 이동, 방향 유지)
PARKED ──(✓ 확정 / 마우스 좌클릭 / Enter·Space)──▶ RESOLVING (연쇄 연출) ──▶ IDLE (+1장 보충)
CARRYING|PARKED ──(✕ / Esc / 우클릭 / 고스트를 손패로 끌어 놓기 / 같은 손패 카드 재탭)──▶ IDLE
```

- **피벗 모델:** 2칸 조각은 *피벗 칸*(카드 왼쪽 반쪽)과 *위성 칸*으로 구성. 포인터 아래 칸 = 피벗. 회전 = 위성이 피벗 둘레 6방향을 시계방향으로 도는 것.
- 같은 손패 카드를 들고 있으면 **마지막 방향을 기억**한다(카드별).

### 1.2 회전 — 입력을 2개로 줄인다

| 입력 | 마우스·키보드 | 터치 |
|---|---|---|
| **주 회전** | 마우스 휠 1칸 = 60° (또는 R / Shift+R 역방향) | **고스트를 탭** = 시계방향 60° |
| **직접 방향 지정** | 위성 후보 점(아래) 클릭 | 위성 후보 점 탭 |
| 제거 | 우클릭 회전 (우클릭은 **취소**로 재할당), ↻ 손패 버튼 | ↻ 손패 버튼, "같은 칸 두 번 탭" |

- **위성 후보 점(petal):** PARKED 상태에서 피벗 주변 6칸 중 놓을 수 있는 칸에 작은 점(지름 ≥ 칸 폭 35%, 위성 지형색 + 지형 아이콘)을 띄운다. 탭하면 그 방향으로 바로 회전. → 회전을 "몇 번 돌리기"가 아니라 "저기로"로 바꿔 시행착오를 없앤다.
- **⇄ 뒤집기:** 고스트 툴바에 버튼 하나. 같은 두 칸에서 반쪽 지형을 맞바꿈(피벗↔위성). "물은 여기, 집은 저기"를 1탭으로.
- 회전 애니메이션 120ms, 위성이 원호를 그리며 이동(방향 감각 유지).

### 1.3 고스트 툴바 (조작부는 조각에 붙는다)

PARKED 고스트 바로 옆(화면 가장자리 반대편, 고스트·미리보기 라벨과 겹치지 않는 쪽)에 떠 있는 캡슐:

```
 [ ↻ ]  [ ⇄ ]  [ ✕ ]  [   ✓ 놓기   ]
```

- 버튼 최소 48×48dp(폰), ✓는 다른 버튼의 2배 폭, 강조색. ✓는 무효 배치일 때 비활성 + 사유 표시.
- 마우스: 툴바는 PARKED에서도 표시하되, 숙련자는 좌클릭 한 번으로 확정 가능(아래 1.5).
- 툴바는 고스트를 따라 이동하며, 카메라가 움직여도 고스트에 고정.

### 1.4 스냅·손가락 가림·유효성

- **스냅:** 포인터에서 가장 가까운 칸 중심으로 즉시 스냅(이동 보간 ≤ 80ms). 칸 사이 경계에서 깜빡임 방지용 히스테리시스: 현재 칸 반경의 15% 안쪽으로 다시 들어오기 전엔 바뀌지 않음.
- **손가락 가림(터치 드래그 중):** 고스트를 손가락 위 1.2칸만큼 띄워 그린다(피벗 = 손가락 위 칸). 손가락을 떼면 그 칸에 PARKED. 폰에서 칸이 40px 미만으로 보이면 드래그 중 손가락 위에 원형 돋보기(2×) 표시.
- **스마트 방향:** 현재 방향이 이 칸에서 무효인데 다른 방향은 유효하면, 시계방향으로 가장 가까운 유효 방향으로 **자동 회전**하고 위성에 작은 흔들림(150ms). 설정에서 끌 수 있음. (유효 방향이 없으면 무효 표시)
- **놓을 수 없는 칸 미리 표시:** CARRYING 시작 시, 어떤 방향으로도 들어갈 수 없는 칸은 25% 어둡게 + 점무늬. 놓을 수 있는 영역이 한눈에 보임.
- **무효 피드백 (색만으로 표현 금지):**
  - 문제 반쪽에 빗금 + ✕ 아이콘, 고스트 전체 50% 투명.
  - 사유 칩 1줄이 고스트 위에: "바다에는 못 놓아요" / "산이에요" / "이미 땅이 있어요" / "섬 밖이에요".
  - 무효 상태에서 확정 시도 → 고스트 좌우 흔들림 200ms + 짧은 둔탁한 소리, **절대 확정되지 않음**.

### 1.5 확정 방식 — 입력별

| 입력 | 확정 | 이유 |
|---|---|---|
| 마우스 | 칸 위 **좌클릭 = 즉시 놓기** (호버 중 미리보기가 이미 보임). 툴바 ✓도 동작 | 호버가 있어 오조작 위험이 낮고, 숙련자 속도 보존 |
| 터치 | **반드시 ✓** (손가락 떼기 = PARKED, 놓지 않음) | 터치는 호버가 없어 미리보기를 볼 단계가 필요. 오배치 = 되돌릴 수 없는 손실 |
| 키보드 | Enter / Space | — |

설정 "항상 확인 버튼으로 놓기"(마우스에도 ✓ 강제)를 제공. 첫 튜토리얼 섬에서는 입력과 무관하게 ✓ 강제(배치 = 의도적 행동임을 학습).

### 1.6 키보드·게임패드 (접근성 / Godot 이식 대비)

| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 손패 선택 | 1 / 2 / 3, Tab 순환 | LB / RB |
| 고스트 이동(칸 단위) | 화살표 또는 W/A/S/D (위·아래는 지그재그 행 이동) | 왼쪽 스틱 / 방향패드 |
| 회전 / 역회전 | R / Shift+R | X / Y |
| 뒤집기 | F | 왼쪽 스틱 클릭 |
| 확정 / 취소 | Enter·Space / Esc | A / B |
| 카메라 팬 · 줌 · 회전 | Shift+화살표 · +/- · Q/E | 오른쪽 스틱 · LT/RT · 오른쪽 스틱 클릭+좌우 |
| 섬 전체 보기 | Home 또는 0 | View/Select |

## 2. 카메라

### 2.1 기본 프레이밍 (Auto-frame)

- **목표:** 섬 외곽(바다 테두리 포함) 바운딩박스가 *플레이 영역*(HUD를 뺀 영역)의 **높이 90% 또는 폭 90% 중 먼저 닿는 쪽**까지 차게 한다.
- 섬 시작·화면 크기 변경·회전(가로/세로) 시 자동 재프레이밍(300ms ease-out).
- 현재 대비 기대 효과: 1280×720에서 섬 표시 폭 ~45% → ~85%, 칸 크기 약 1.8배.

### 2.2 줌·팬·회전

| 동작 | 마우스 | 터치 | 범위·규칙 |
|---|---|---|---|
| 줌 | 휠 (조각을 **들고 있지 않을 때**) · Ctrl+휠은 항상 줌 · 트랙패드 핀치 | 두 손가락 핀치 | 기본 프레임 = 1.0×, 범위 0.85×–2.5×. 줌 기준점 = 커서/두 손가락 중점 (기준점 아래 칸이 1칸 이상 밀리지 않음) |
| 팬 | 빈 바다·땅에서 좌드래그 또는 가운데 버튼 드래그 / 스페이스+드래그 | 빈 곳 한 손가락 드래그 (조각/고스트에서 시작하면 조각 이동) | 섬 바운딩박스 30% 이상이 항상 화면 안에 남도록 클램프 |
| 회전 | Q / E, 우하단 ⟲⟳ | 두 손가락 비틀기 → 손을 떼면 **60° 단위로 스냅** | 6방향 고정. 나침반 아이콘(북쪽 표시) 탭 = 기본 방향 복귀 |
| 전체 보기 | 빈 곳 더블클릭, Home | 빈 곳 두 번 탭 | 2.1 프레이밍 복귀 |

- **휠 충돌 해소:** 조각을 들고 있을 때 휠 = 회전, 아닐 때 휠 = 줌. 상태 표시: 들고 있을 때 커서 옆에 작은 ↻ 아이콘.
- **우클릭:** 조각 들고 있음 = 취소, 아님 = 카메라 회전 드래그(기존 유지).

### 2.3 배치 중 초점 (Focus on placement)

- PARKED 고스트 + 미리보기 라벨이 화면 가장자리 12% 안으로 들어가면, 전부 보이도록 **부드럽게 팬**(줌은 바꾸지 않음, 250ms). 줌 변경은 항상 플레이어가 결정.
- 카드를 든 순간 줌이 0.9× 미만이면 1.0×로 복귀(배치 시 칸 정밀도 확보).
- 연쇄 연출 중 카메라는 **움직이지 않는다**(멀미 방지, 연출은 HUD 칩 위로 흐름 — 4.3).

### 2.4 제스처 우선순위 (터치 충돌 표)

| 시작 지점 | 한 손가락 탭 | 한 손가락 드래그 | 두 손가락 |
|---|---|---|---|
| 손패 카드 | 들기(CARRYING→고스트는 섬 중앙 근처 첫 유효 칸에 PARKED) | 들고 끌기 | 무시 |
| 고스트 | 회전 | 고스트 이동 | 카메라 |
| 위성 후보 점 | 그 방향으로 회전 | 고스트 이동 | 카메라 |
| 빈 칸 (조각 들고 있음) | 고스트를 그 칸으로 이동 | 카메라 팬 | 카메라 |
| 빈 칸 (조각 없음) | 칸 정보 툴팁 (무리 크기) | 카메라 팬 | 카메라 |

- 탭 판정: 이동 < 10px 그리고 < 250ms. 드래그 시작 임계값 10px.

## 3. HUD 레이아웃

### 3.1 원칙

- **기본 화면에 문장 0개.** 숫자·아이콘·핍(pip)만. 문장은 코치 마크와 세부 서랍에서만.
- 좌·우 사이드 패널 **삭제**. 자원 트랙 → 상단 칩, 미리보기 → 섬 위 + 칩 위, 텍스트 목록 → 선택형 서랍.

### 3.2 16:9 데스크톱 (1280×720 기준)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 🌱여름 ●●●○○○   [🌾 14◔]→[👤 7◕]→[🪵 20◑]→[🐑 10○]→[🐟 22◔]↩   ★73  ⋯ │ ← 상단 바 56px
├──────────────────────────────────────────────────────────────────────┤
│                                                                ⓘ    │
│                                                                      │
│                    (섬 — 플레이 영역의 90%)                           │
│                                                                      │
│                                                          ⟲ 🧭 ⟳     │
├──────────────────────────────────────────────────────────────────────┤
│                    [카드1]   [카드2]   [카드3]                        │ ← 손패 바 ~110px
└──────────────────────────────────────────────────────────────────────┘
```

- **계절:** 계절 아이콘 + 6개 점(놓은 장수). "전체 9/24"는 ⋯ 메뉴/서랍으로.
- **점수:** ★ 숫자 하나. 균형 섬일 때는 가장 낮은 칩에 왕관 대신 "기준" 표시 테두리.
- **⋯ 메뉴:** 다시 · 새 섬 · 균형 섬 토글 · 설정 · 규칙 다시 보기(튜토리얼).
- **ⓘ:** 세부 서랍 열기(3.5).

### 3.3 자원 칩 (트랙 = 링)

```
  ╭───────╮
  │ 🌾 14 │   링 = 다음 문턱까지 진행(5칸 세그먼트, 14 → 4/5 채움)
  ╰───────╯   링 바깥 오른쪽 작은 꼬리 → 다음 칩으로 가는 연결선
```

- 칩 = 아이콘 + 현재값 + **5세그먼트 링**(문턱까지 진행). "5마다"를 읽을 필요 없이 링이 차면 터진다는 것이 보임.
- **칩 순서 = 연쇄 고리 순서.** 곡식 → 주민 → 목재 → 양모 → 물고기 → (↩ 곡식). 칩 사이 연결선 위에 보너스 크기 "+2"를 작게. *화면 왼쪽→오른쪽 순서 자체가 연쇄 규칙을 설명한다.*
- 링 4/5 상태: 링이 천천히 숨쉬듯 빛남(문턱 임박 신호). 감소 모션 설정 시 정적 강조 테두리.
- 칩 탭/호버 = 툴팁 2줄: "🌾 곡식 ← 밭 무리에서 얻어요 / 링이 차면 → 👤 주민 +2 (풍년)".
- 색만으로 구분하지 않음: 모든 칩·지형에 고유 아이콘 + 링 세그먼트에 지형별 무늬(현재 프로토타입의 빗금 미리보기 무늬 유지).

### 3.4 미리보기 — 섬 위 + 칩 위 (텍스트 목록 대체)

PARKED/호버 상태에서:

1. **섬 위:** 발동할 무리 전체 칸에 지형색 외곽선 글로우 + 무리 중심 위에 배지 하나 "**+6 🐟**".
   - 같은 무리에 두 반쪽이 모두 닿으면 배지 **하나로 합산**("+2 +2" 겹침 제거 → "+4 🪵", 작은 "×2" 표시). 규칙 변경 아님, 표시만.
   - 배지는 서로 겹치면 위로 밀어 배치(충돌 회피), 고스트 툴바와도 겹치지 않음.
2. **칩 위:** 늘어날 링 세그먼트가 빗금으로 미리 채워지고, 칩 숫자 옆 "+6".
   - 문턱을 넘으면: 그 칩 링에 ★ 표시 + **점선 화살표가 다음 칩으로** 뻗고 화살표 위 "+2". 다음 칩도 빗금 미리 채움. 연쇄 깊이만큼 화살표가 이어진다.
3. **연쇄 배지:** 고스트 툴바 위에 "연쇄 3" (깊이 0이면 표시 안 함).
4. 점수 변화: ★73 옆에 "→87" 작게.

→ 플레이어는 섬과 상단 바만 보고 "여기 두면 물고기가 차고 → 곡식 → 주민까지 넘어간다"를 읽는다. 미리보기와 실제 결과의 시각 언어가 같다(4.3) — Pillar 4.

### 3.5 세부 서랍 (선택)

- 데스크톱: 오른쪽에서 밀려나오는 320px 서랍. 폰: 아래에서 올라오는 시트(화면 높이 60%).
- 내용: ① 현재 미리보기의 단계별 텍스트(기존 목록, 축약형), ② 연쇄 고리 다이어그램(5칩 원형 배치 + 각 보너스 이름·크기), ③ 계절 정보(남은 장수, 계절 끝 식량 소비 예측).
- 기본 닫힘. 열린 상태를 기억. 서랍이 열려도 섬은 가려지지 않게 플레이 영역을 줄이고 재프레이밍.

## 4. 규칙을 배우게 하기

### 4.1 튜토리얼 섬 4단계 (각 1~3장, 전체 ≤ 3분)

작은 섬(반지름 2, 19칸), 손패 고정 각본. 각 단계는 **한 가지 개념만**, 말보다 행동 먼저. 단계 사이 화면 전환 없이 섬이 "자라며" 다음 단계로.

| 단계 | 가르칠 것 | 섬·손패 설정 | 성공 조건 | 코치 문구 (최대 1줄) |
|---|---|---|---|---|
| T1 놓기·돌리기 | 들기 → 돌리기 → 확정 | 밭 2칸 미리 배치. 손패: 밭+숲 1장. 유일한 정답 자리는 **회전해야** 들어감 | 밭이 기존 밭에 닿게 놓기 | "카드를 골라 섬에 올려요" → (무효 방향이면) "조각을 탭하면 돌아가요" → "✓로 놓아요" |
| T2 무리 = 수확 | 맞닿은 같은 종류 무리 크기만큼 얻음 | 손패 2장: 작은 무리 vs 큰 무리에 닿는 자리 둘 다 가능 | 큰 무리 쪽(+4 이상)에 놓기 | "같은 땅끼리 많이 붙을수록 더 많이 얻어요" (미리보기 배지가 +1 vs +4를 보여줌) |
| T3 링 = 보너스 | 링 5칸 차면 다음 칩 보너스 | 곡식 링 4/5, 주민 칩만 추가 표시. 손패: 밭 포함 1장 | 곡식 링 채우기 | "링이 다 차면 옆 자원에 보너스!" (화살표 연출을 처음 보여줌) |
| T4 연쇄 | 보너스가 또 링을 채움 | 곡식 4/5, 주민 4/5, 목재 칩 등장. 손패 2장 중 1장만 2단 연쇄 | 연쇄 2 달성 | "보너스가 또 링을 채우면… 연쇄!" |

- T1~T4는 실패 불가(무효 배치는 그냥 안 놓아짐, 틀린 선택은 결과를 보여준 뒤 "한 번 더?" 1회 되돌리기 제공).
- 튜토리얼 후 **섬 1**은 컨셉 문서의 온보딩 곡선을 따른다(밭·숲 위주, 트랙 3개 — 5장 참고). 계절·식량은 섬 1의 첫 계절 끝에서 코치 마크로 소개.
- ⋯ 메뉴 "규칙 다시 보기"로 언제든 재생. 건너뛰기 버튼은 T1부터 노출(재방문자용).

### 4.2 상황별 코치 마크

규칙: 한 번에 하나, 한 턴에 최대 하나, 행동하면 사라짐, 각 마크는 평생 1회(설정에서 초기화). 섬 위/칩 위에 말풍선 + 대상 강조, 화면 어둡게 하지 않음(게임 흐름 유지).

| 트리거 | 위치 | 문구 |
|---|---|---|
| 처음으로 칩 링 4/5 | 해당 칩 | "한 칸만 더 차면 보너스" |
| 손패 중 +4 이상 무리를 만들 수 있는데 3턴 동안 +2 이하만 놓음 | 큰 무리 | "큰 무리에 붙이면 더 많이 얻어요" |
| 무효 배치 첫 시도 | 고스트 | 사유 칩(1.4) + "조각을 탭하면 돌아가요" |
| 첫 연쇄 2 이상 미리보기 | 연쇄 배지 | "화살표를 따라가 보세요 — 한 장으로 세 번!" |
| 첫 계절 끝 직전 턴 | 주민 칩 | "계절이 끝나면 주민이 곡식을 먹어요 (🌾 −4)" |
| 10초 동안 아무 입력 없음 (튜토리얼 이후 섬 1만) | 손패 | 카드 가볍게 들썩임 (문구 없음) |

### 4.3 연쇄 이야기 연출 (확정 후 RESOLVING)

미리보기의 점선 화살표가 **실선으로 "실제로 일어나는"** 것 — 같은 시각 언어.

1. **수확 (0–400ms):** 무리 칸들이 피벗에서 바깥으로 차례로 반짝, 자원 아이콘 토큰 N개(최대 6개, 그 이상은 숫자 토큰)가 무리에서 **해당 칩으로 날아감**. 칩 숫자 카운트업, 링 세그먼트 채워짐.
2. **문턱 (링 완성 시):** 링 한 바퀴 빛남 + 칩이 살짝 튐 + ★. 링은 비워지며 다음 바퀴 시작(현재 값의 5의 배수 단위).
3. **보너스 이동 (단계당 350ms):** 칩에서 다음 칩으로 **곡선 화살표가 그려지고** "+2" 토큰이 화살표를 따라 이동 → 다음 칩 링 채움 → 또 문턱이면 반복. 상단 바 위의 "연쇄 N" 카운터가 단계마다 커짐.
4. **섬 반응:** 보너스마다 섬 위 해당 오브젝트가 반응(풍년 → 집에서 주민이 걸어 나옴, 울타리 → 목장 울타리 생김 등 — 시각 디자인은 art-director 결정).
5. **마무리:** 연쇄 2+는 짧은 축하 배지("연쇄 3!") 1초, 섬을 가리지 않는 상단 바 아래 위치. 기존 큰 배너 3장 겹침(03b) 삭제.

- 총 길이 상한 2.5초(깊은 연쇄는 단계당 시간 자동 단축). **탭/클릭/아무 키 = 빨리 감기**(남은 단계 즉시 적용, 결과 화살표 1초 유지).
- `prefers-reduced-motion`/설정: 토큰 비행 없음, 칩 숫자 즉시 변경, 정적 화살표 1.5초 표시.
- 연출 중 다음 카드 선택 가능(연출 즉시 완료 처리) — 숙련자가 기다리지 않게.

## 8. 구현 메모 (ui-programmer 참고 — 구현 지시 아님)

- `simulate()`는 그대로 미리보기·확정 공용. 3.4/4.3의 칩 화살표는 `simulate()` 결과의 보너스 단계 배열을 그대로 그린다(미리보기 = 점선, 확정 = 실선 애니메이션).
